# TelegramBot-AIGateway-CloudflareWorkers-fa
### دروازه‌ی هوش مصنوعی سرورلس برای تلگرام — روی Cloudflare Workers

## 📖 معرفی پروژه
یک ربات تلگرام قدرتمند، سریع و کاملاً رایگان برای اتصال به مدل‌های هوش مصنوعی
رایگان **Cloudflare Workers** و پایگاه‌داده‌ی **D1** اجرا می‌شود. هیچ نیازی به:

- ❌ سرور اختصاصی (VPS)
- ❌ هاست یا دامنه
- ❌ کتابخانه‌ی خارجی (npm package)
- ❌ ابزار خط فرمان مثل Wrangler CLI

نیست. تمام کد در **یک فایل جاوااسکریپت** نوشته شده و مستقیماً از طریق ویرایشگر آنلاین
کلودفلر قابل دیپلوی است.

این پروژه مثل یک **پروکسی/گیت‌وی هوشمند** بین کاربران تلگرام و APIهای هوش مصنوعی
(مثل Groq، OpenRouter، DeepSeek، Google Gemini و هر سرویس OpenAI-Compatible دیگری)
عمل می‌کند و یک پنل مدیریت کامل داخل خود تلگرام در اختیار شما می‌گذارد.

---

## ✨ ویژگی‌های کلیدی

### 👤 برای کاربران عادی
- 💬 چت هوشمند با حافظه‌ی مکالمه (Context Memory تا ۵ پیام آخر)
- 🖼 پشتیبانی از ارسال عکس و تحلیل تصویر (Vision) با مدل‌های چندوجهی
- 🎭 امکان انتخاب شخصیت (Persona) دلخواه برای هوش مصنوعی
- 🧹 پاک کردن حافظه و شروع گفتگوی تازه با یک دکمه
- 👤 مشاهده‌ی پروفایل، اعتبار باقیمانده و مدل فعال
- ⏳ نمایش زنده‌ی وضعیت پردازش (Fake Streaming) به‌جای انتظار خاموش
- 🎨 خروجی تمیز و بدون خطای فرمت‌بندی (HTML Sanitizer اختصاصی)

### 👑 برای مدیر (ادمین)
- 📊 داشبورد آماری زنده (تعداد کاربران، پیام‌های امروز، وضعیت ربات)
- 🔌 مدیریت نامحدود پروایدرهای هوش مصنوعی (افزودن/حذف/فعال‌سازی)
- 🔄 دریافت خودکار لیست مدل‌های هر پروایدر با یک کلیک
- 🤖 انتخاب مدل پیش‌فرض سراسری با کیبورد صفحه‌بندی‌شده
- 👥 مدیریت کامل کاربران: مسدودسازی، افزایش اعتبار، تنظیم مدل اختصاصی
- 🎭 ساخت و مدیریت شخصیت‌های سفارشی نامحدود
- 📢 ارسال پیام همگانی (Broadcast) به تمام کاربران
- 🔒 سوییچ آنی حالت ربات بین عمومی و خصوصی
- 🔔 اعلان لحظه‌ای عضویت کاربران جدید

### ⚙️ معماری فنی
- ✅ سازگار با APIهای **OpenAI-Compatible** (Groq, OpenRouter, DeepSeek, Together.ai و ...)
- ✅ سازگار با **Google Gemini API** (تشخیص خودکار نوع پروایدر)
- ✅ مدیریت خودکار Rate Limit تلگرام (خطای ۴۲۹)
- ✅ عدم بروز خطای Timeout با استفاده از `ctx.waitUntil()`
- ✅ اختصاصی Sanitizer جلوگیری از کرش پیام‌های فرمت‌دار
- ✅ کاملاً رایگان روی پلن Free کلودفلر (تا ۱۰۰هزار درخواست در روز)

## 🚀 نصب سریع (خلاصه)

```bash
# ۱. کد worker.js را کپی کن
# ۲. یک Worker جدید در Cloudflare بساز و کد را پیست کن
# ۳. یک D1 Database بساز و با نام "DB" به Worker متصل کن
# ۴. متغیرهای BOT_TOKEN و ADMIN_ID را در Settings > Variables تنظیم کن
# ۵. Deploy بزن
# ۶. مرورگر را باز کن:
https://YOUR-WORKER.workers.dev/setup?key=YOUR_ADMIN_ID
# ۷. به ربات در تلگرام /start بزن 🎉
```
