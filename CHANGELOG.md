# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-07-11

### Features
- Multi-provider AI gateway (OpenAI-compatible + Gemini)
- Admin panel with inline keyboard inside Telegram
- User management (credits, ban/unban, custom models)
- Chat memory with 10-message window
- Image analysis support
- Custom AI personas
- Broadcast messaging
- Rate limit (429) handling
- Fake streaming progress bar
- Daily credit reset via Cron Triggers

### Supported Providers
- Google Gemini
- Groq
- Mistral AI
- OpenRouter
- Cerebras
- OpenModel
- Cohere
- DeepSeek
- OpenAI

## [1.0.0] - 2026-07-10

### Initial Release
- Basic AI chat bot
- Cloudflare Workers serverless architecture
- D1 database integration
